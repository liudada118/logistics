## 一、概述

本文档基于对蓝桥T9系统的实际登录分析，结合系统已上线的功能模块，为物流管理系统提供完整的功能测试用例。测试覆盖登录鉴权、受理开单、运输管理（发货→到货→签收）、财务中心、基础数据管理五大核心模块，共计 **42 个测试用例**，优先级分为 P0（必测）、P1（重要）、P2（一般）三级。

## 三、业务流程总览

T9系统的核心业务流程如下，测试用例按此流程顺序编排：

```
受理开单（待调度）
    ↓
发货库存（已发货）
    ↓
运输中（已发车）
    ↓
到货确认（已到货）
    ↓
签收登记（已签收）/ 异常登记（异常）
    ↓
财务结算（应收确认 / 代收货款结算）
```

## 七、附录：蓝桥T9系统参考字段

通过实际登录蓝桥T9系统（企业ID: 92392，网点: 合肥）分析，T9受理开单列表包含以下完整字段，可作为功能对齐参考：

**运单基础信息**：状态、运单号、货号、托运日期、发站、中转地、到站

**收发货信息**：发货人、发货人手机、发货人电话、收货人、收货人手机、收货人电话、收货地址、发货地址、实际发站

**货物信息**：品名、包装、件数、立方、重量

**费用信息**：现付、提付、回单付、月结、货款扣、基本运费、折扣运费、运费折扣、保险费、接货费、运费合计、净运费、净产值

**结算信息**：回扣、回扣现返、回扣欠返、垫付中转费、垫付现返、垫付欠返、结算中转费

**T9营运中心完整流程**：网络订单 → 受理开单 → 发货库存 → 分单配载 → 开派车单 → 车辆跟踪 → 到货确认 → 到货库存 → 客户提货 / 送货上门 / 终端代理 → 签收登记 / 异常登记

**T9财务中心完整流程**：现金录入 / 银行存款录入 → 管理费用请款 / 业务支出请款 → 请款审批 → 请款结果 → 现金日记账 / 银行存款日记账 → 出纳审核 → 出纳扎帐 → 上缴账款 → 到款确认 → 资金调拨
